# Configurations (Project Save/Load) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the ability to save and load named configurations (projects) that partition the soundstage hierarchy while keeping the library global.

**Architecture:** A `configurations` table with a `configuration_id` FK on the `groups` table scopes the entire hierarchy tree per config. Autosave continues to work as-is (mutations write to SQLite under the active config). "Save As" deep-copies all hierarchy rows. The frontend gets a config picker component in the SoundstageView header.

**Tech Stack:** Rust (rusqlite, uuid, serde, ts-rs), Vue 3 (Pinia, Vuetify 4), Tauri 2 IPC

```rust
/// Migrates from schema v1 to v2: creates the configurations table,
/// inserts a "Default" configuration, and adds configuration_id to groups.
pub fn migrate_v1_to_v2(conn: &Connection) -> Result<(), String> {
    use std::time::{SystemTime, UNIX_EPOCH};

    let version: String = conn
        .query_row("SELECT value FROM meta WHERE key = 'schema_version'", [], |row| row.get(0))
        .map_err(|e| format!("Failed to read schema_version: {e}"))?;

    if version != "1" {
        return Ok(()); // Already migrated or newer
    }

    let config_id = Uuid::new_v4().to_string();
    let created_at = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .expect("system time before epoch")
        .as_millis()
        .to_string();

    conn.execute_batch("BEGIN TRANSACTION;")
        .map_err(|e| format!("Failed to begin migration transaction: {e}"))?;

    let result = (|| -> Result<(), String> {
        // 1. Create configurations table
        conn.execute_batch("
            CREATE TABLE IF NOT EXISTS configurations (
                id         TEXT PRIMARY KEY,
                name       TEXT NOT NULL,
                created_at TEXT NOT NULL,
                sort_order INTEGER NOT NULL
            );
        ").map_err(|e| format!("Failed to create configurations table: {e}"))?;

        // 2. Insert Default configuration
        conn.execute(
            "INSERT INTO configurations (id, name, created_at, sort_order) VALUES (?1, 'Default', ?2, 1000)",
            params![config_id, created_at],
        ).map_err(|e| format!("Failed to insert default configuration: {e}"))?;

        // 3. Recreate groups table with configuration_id FK
        conn.execute_batch("
            CREATE TABLE groups_new (
                id               TEXT PRIMARY KEY,
                name             TEXT NOT NULL,
                sort_order       INTEGER NOT NULL,
                configuration_id TEXT NOT NULL REFERENCES configurations(id) ON DELETE CASCADE
            );
        ").map_err(|e| format!("Failed to create groups_new: {e}"))?;

        conn.execute(
            "INSERT INTO groups_new (id, name, sort_order, configuration_id)
             SELECT id, name, sort_order, ?1 FROM groups",
            params![config_id],
        ).map_err(|e| format!("Failed to copy groups data: {e}"))?;

        conn.execute_batch("
            DROP TABLE groups;
            ALTER TABLE groups_new RENAME TO groups;
        ").map_err(|e| format!("Failed to swap groups table: {e}"))?;

        // 4. Set active configuration
        conn.execute(
            "INSERT OR REPLACE INTO meta (key, value) VALUES ('active_configuration_id', ?1)",
            params![config_id],
        ).map_err(|e| format!("Failed to set active configuration: {e}"))?;

        // 5. Bump schema version
        conn.execute(
            "UPDATE meta SET value = '2' WHERE key = 'schema_version'",
            [],
        ).map_err(|e| format!("Failed to update schema version: {e}"))?;

        Ok(())
    })();

    match result {
        Ok(()) => {
            conn.execute_batch("COMMIT;")
                .map_err(|e| format!("Failed to commit migration: {e}"))?;
            Ok(())
        }
        Err(e) => {
            let _ = conn.execute_batch("ROLLBACK;");
            Err(e)
        }
    }
}
```

pub fn delete_configuration(container: &AppStateContainer, config_id: String) -> Result<AppState, String> {
    with_db(container, |conn| {
        // Count existing configs — cannot delete the last one
        let count: i64 = conn
            .query_row("SELECT COUNT(*) FROM configurations", [], |row| row.get(0))
            .map_err(|e| format!("Failed to count configurations: {e}"))?;
        if count <= 1 {
            return Err("Cannot delete the only configuration".to_string());
        }

        // If deleting the active config, switch to the first remaining one
        let active_id = database::get_active_configuration_id(conn)?;
        if active_id == config_id {
            let next_id: String = conn
                .query_row(
                    "SELECT id FROM configurations WHERE id != ?1 ORDER BY sort_order ASC LIMIT 1",
                    params![config_id],
                    |row| row.get(0),
                )
                .map_err(|e| format!("Failed to find next configuration: {e}"))?;
            configurations::set_active_configuration(conn, &next_id)?;
        }

        configurations::delete_configuration(conn, &config_id)?;
        database::load_full_state(conn)
    })
}
